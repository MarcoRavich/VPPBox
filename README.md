# VPPBox

A Powershell GUI inspired by Stuart Cameron's [VapourBox](https://github.com/StuartCameronCode/VapourBox#readme) that relies exclusively on rigaya's HWEncs Video Pre-Processing filters.

## Features

- VapourBox-inspired desktop workflow with comparison preview, video queue and settings panel.
- Draggable before/after overlay preview box.
- Multi-file queue; input/output selection; H.264 and HEVC; CQP quality; audio copy.
- VPP settings for KNN denoise, deband, unsharp, and resize, with a generated encoder command preview.
- Quick starting presets for detail-preserving cleanup, debanding, and 1080p resize.
